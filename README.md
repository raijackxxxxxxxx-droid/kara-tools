# カラの道具箱（Kara Software Works）

ブラウザで開くだけで使える、小物ツールの置き場です。
自分が欲しくて作ったものを、ついでに公開しています。全部無料、データの外部送信なし。

公開ページ（GitHub Pages）: トップページは `index.html` です。

## ツール一覧

| ツール | 説明 |
|---|---|
| [参加枠まわし君（仮）](tools/participation-queue/) | 参加型配信の順番管理。参加回数が一番少ない人から次が決まる裏方ツール |
