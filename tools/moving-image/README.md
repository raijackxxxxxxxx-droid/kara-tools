# 動く画像メーカー（仮）

読み込んだ画像に変化のステップをつないで動きを付け、WebM動画として書き出す単一HTMLツール。「カラの道具箱」の6つ目（動く文字メーカーの画像版）。

## 使い方

1. 画像を読み込みます（透過PNG推奨）。
2. 全体の設定（画面サイズ・背景・フェードイン／アウト）を決めます。
3. スタートの状態（大きさ・位置・傾き・左右反転）を決めます。
4. ステップを追加していきます。各ステップは「サイズ／傾き／移動／透明度／左右反転」の状態変化と、「その場の動き・変形」（波うち／ぷるぷる／ぐるぐる／ゆらゆら／跳ねる／ドキドキ／ふわふわ／キラキラ）と、時間（0.5〜5秒）の組み合わせです。最大8ステップ。「スタートに戻る」ステップをワンタップで足せます。プレビューは常時表示の3モード切替（出発点／着地点の静止画と全部再生）。静止画は設定中のステップの開始・終了状態をその場で表示し、全部再生では下書きステップの区間に、画像に沿って緑の点線枠（下書き表示）が出ます。静止画でも、透明度やフェードで画像が見えにくい時は、画像の位置に点線枠が出ます。下書きは「ステップを追加」まで書き出しに反映されません。
5. WebMで書き出します（スタートから最後のステップまでを1回分録画）。

## 仕様メモ

- 状態変化はステップの時間いっぱいを使ってなめらかに補間され、次のステップへ引き継がれます。「その場の動き・変形」はそのステップ内だけ効き、終わると元の状態に戻ります（ぐるぐるはその時間で1回転）。
- 指定はすべてプリセット選択式（数値入力なし）。細かい調整は編集ツールの領分、という道具箱の線引きに従います。
- 画面サイズ・背景を変えてもステップは消えません（位置・大きさは割合ベースで保持）。
- 背景は透過のほかクロマキー用3色（緑・青・マゼンタ）と黒・白。書き出しは canvas.captureStream + MediaRecorder（VP9優先）。透過が効くかは編集アプリ側の対応によります。
- 画像は端末内でのみ処理され、外部送信されません。通信なしで動作します。
