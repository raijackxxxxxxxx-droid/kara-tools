# 画像合成君（仮）

画像を1枚ずつ置いて「合成」ボタンで焼き込み、1枚絵を作る単体HTMLツールです。レイヤーを持たない代わりに、操作が「置く → 合わせる → 焼く」の繰り返しだけになっています。

## 使い方

1. 台紙のサイズを選ぶ（サムネ 1280×720／フルHD 1920×1080／正方形 1080×1080／縦長 1080×1920／画像に合わせる）。切り替えると最初からやり直しになります。
2. 画像を選ぶと、全体が収まる大きさで真ん中に仮置きされます。
3. 大きさ（全面／収める／100%・75%・50%・33%・25%＋±5%微調整、基準は高さ／幅の切り替え）、置き場所（9方向パッド＋端は少し内側）、微調整（十字キー、移動量 1／10／50px、PCでは矢印キーも可）、左右反転で合わせます。
4. 「この位置で合成（焼き込む）」を押すと台紙に焼き込まれます。間違えたら「1つ戻す」で直前の合成だけ取り消せます。
5. PNG／JPEGで保存します。仮置き中の画像がある間は保存できないので、合成するか仮置きをやめてから保存してください。

## 仕様・メモ

- 台紙の初期色は黒（白に切り替えると最初からやり直し）。
- 「画像に合わせる」を選ぶと、次に読み込んだ画像がそのまま台紙になり、その画像の大きさが台紙サイズになります。週間スケジュールのテンプレ画像など、自分の画像を土台にする用途向けです。とても大きい画像を台紙にすると、スマホでは処理が重くなることがあります。
- プレビュー表示は「全体を縮小」（画面の高さに収まるよう縮小、初期設定）と「大きくスクロール」（大きく表示してプレビューの中でスクロール）を切り替えられます。縦長の台紙でも操作ボタンに届かなくならないための仕組みです。保存される画像の大きさは表示方法では変わりません。
- 焼き込み式なので、合成済みの画像を個別に動かしたり消したりはできません。
- 仮置き中の画像には編集中だけ点線の枠が表示されます（保存には入りません）。
- 文字画像は「もじPNGメーカー」で作った透過PNGを置く想定です。
- 処理はすべてブラウザ内で完結し、外部送信はありません。ネット接続も不要です。
