# サムネ合成君（仮）

画像を1枚ずつ置いて「合成」ボタンで焼き込み、サムネイル用の1枚絵（1280×720）を作る単体HTMLツールです。レイヤーを持たない代わりに、操作が「置く → 合わせる → 焼く」の繰り返しだけになっています。

## 使い方

1. 画像を選ぶと、全体が収まる大きさで真ん中に仮置きされます。
2. 大きさ（全面／収める／100%・75%・50%・33%・25%＋±5%微調整、基準は高さ／幅の切り替え）、置き場所（9方向パッド＋端は少し内側）、微調整（十字キー、移動量 1／10／50px、PCでは矢印キーも可）、左右反転で合わせます。
3. 「この位置で合成（焼き込む）」を押すと台紙に焼き込まれます。間違えたら「1つ戻す」で直前の合成だけ取り消せます。
4. PNG／JPEGで保存します。仮置き中の画像がある間は保存できないので、合成するか仮置きをやめてから保存してください。

## 仕様・メモ

- 台紙は1280×720固定、初期色は黒（白に切り替えると最初からやり直し）。
- 焼き込み式なので、合成済みの画像を個別に動かしたり消したりはできません。
- 仮置き中の画像には編集中だけ点線の枠が表示されます（保存には入りません）。
- 文字画像は「もじPNGメーカー」で作った透過PNGを置く想定です。
- 処理はすべてブラウザ内で完結し、外部送信はありません。ネット接続も不要です。
