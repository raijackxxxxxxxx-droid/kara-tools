# 下地づくり君（仮）

画像に「文字を載せるための下地」を付けるだけのツールです。
サムネイルや告知画像づくりの下ごしらえを想定しています。

ブラウザで開くだけで使えます。ネット接続も不要です（画像はブラウザの中だけで処理されます）。

## 使い方

1. 画像を開く（タップで選択、PCではドラッグ＆ドロップでも可）
2. 「文字の下地」か「16:9・両脇ぼかし」を選ぶ
3. 下地の場合はプリセットを選ぶだけ（濃さの微調整もできます）
4. 「PNGで保存」または「JPEGで保存」。スマホでは、表示される保存用画像の長押しでも保存できます

## プリセット（文字の下地）

| プリセット | 内容 |
|---|---|
| なし | 何も付けない |
| 下帯・標準 | 下から約38%に、黒のグラデーション（最大 約62%） |
| 下帯・強め | 下から約55%に、濃いめのグラデーション（最大 約85%）。明るい画像用 |
| 上帯 | 上から約30%にグラデーション。上にタイトルを置く用 |
| 全体を少し暗く | 画像全体を一律 約32% 暗くする |
| 周りを少し暗く | 周辺減光。真ん中はそのまま、四隅に向けて最大 約50% 暗くする |
| 下帯・白 | 下から約38%に、白のグラデーション（最大 約78%）。濃い色の文字用 |
| 全体を少し明るく | 画像全体を一律 約25% 明るくする |
| 周りを少し明るく | 周辺を白くする周辺減光。真ん中はそのまま、四隅に向けて最大 約50% 明るくする |

「濃さの微調整」スライダー（50〜150%）で、各プリセットの濃さをまとめて増減できます。

## 16:9・両脇ぼかし

画像を16:9の真ん中に等倍で置き、余った部分を「画像自体をぼかして伸ばした背景」で埋めます。
背景は少し暗くしてあるので、そのまま文字を載せやすいです。設定項目はありません。

- 縦画像 → 両脇がぼかし背景になります
- 16:9より横長な画像 → 上下がぼかし背景になります
- ちょうど16:9の画像 → そのまま出力されます

ファイル名は shimoji.png / shimoji.jpg です。

## 注意

- 画像が外部に送信されることはありません
- とても大きい画像（目安: 2000万画素超）は、スマホでは処理に時間がかかったり保存に失敗したりすることがあります。その場合はPCで試してください
- ぼかしはブラウザの描画機能だけで作っているため、専用編集ソフトのぼかしより少し荒いことがあります
- 動作保証はありません
