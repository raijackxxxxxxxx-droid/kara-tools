# 動く文字メーカー（仮）

文字に動きを付けて、WebM動画として書き出す単体HTMLツールです。ショート動画などの素材作りを想定しています。装飾は最小限で、主役は動きです。

## 使い方

1. 文字を入力します（1行、20文字まで）。
2. 動きを選びます（13種、「動きなし」も含む）。「ループの長さ」と「動きの大きさ」は別々に決められます。大きく＋短く＝早くて激しく、小さく＋長く＝ゆっくり小さく動きます。どちらもプリセットのほかに数字入力でも指定でき、ループは0.5〜10秒、大きさは入力なら最大400%まで（スライダーは200%まで）。「フェードイン・アウト」（なし／短め／ふつう／長め）を選ぶと、どの動きにもループの頭と終わりのフェードを重ねられます。
3. 書体・太さ・文字色・フチ色・フチの太さ・影を選びます。
4. 画面サイズ（縦1080×1920＝Shorts向け／縦720×1280／横1920×1080／横1280×720／正方形1080×1080）と背景（透過／クロマキー用の緑・青・マゼンタ／黒／白）を選びます。
5. 「WebMで書き出す」を押すと、ループ1周分を録画してWebMファイルが出力されます。

## 動きのプリセット（13種）

動きなし／順に跳ねる／波うち／ポップ登場／ゆらゆら／ふわふわ／スライド登場／キラキラ／ドキドキ／くるっと登場／ジェリー／フェード／順にフェード

## 仕様・メモ

- 書き出しはブラウザの録画機能（MediaRecorder）を使います。透過WebMの書き出し・再生はブラウザ差があり、Chrome（Android・PC）推奨です。
- 編集アプリ側で透過WebMが効くかはアプリと版によります。効かない場合はクロマキー用の背景色で書き出して、編集側で色を抜いてください（文字・フチと同系色の背景は避けてください）。
- 「登場」系の動き（ポップ／スライド／くるっと）は、ループ後半は止まった状態で待機し、頭で再び登場します。
- 処理はブラウザ内で完結し、外部送信はありません（フォント読み込みのみ通信します）。
