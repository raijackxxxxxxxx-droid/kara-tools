# 色抜き・フチ取り君（仮）

画像のフチからつながっている背景色だけを抜いて透過にし、そのまま輪郭にフチも付けられる単一HTMLツールです。白背景のイラストやロゴを「ステッカー化」するための道具です。

## 使い方

1. 画像を読み込みます（PNG / JPEG / WebP。大きな画像は最長辺2048pxに縮小して処理します）。
2. 「色抜き」で背景色（四隅から自動判定、ずれていたら色指定で修正）、許容度、エッジの滑らかさを、プレビューを見ながらバーで調整します。抜けるのはフチからつながった色だけで、絵の内側にある同じ色は残ります。指の輪の中など、フチからつながっていない背景は「タップで抜く」をオンにしてその場所をタップすると抜けます。
3. 「この色抜きで確定する」を押すと色抜きが焼き込まれ、「フチ取り」が使えるようになります。フチはオン／オフ、色（白・黒・赤・青・黄＋自由色）、太さ（バー）を選べます。色抜きの設定を変えると、フチ取りは再確定までロックされます。
4. プレビューは画面の高さ40%ほどの枠に収まり、全体／拡大ボタンと枠内スクロールで輪郭を寄って確認できます。
5. PNGで保存します。

## 向いている素材・向いていない素材

- 向いている：白や単色の背景のイラスト、ファンアート、ロゴ、単色背景の生成画像など、背景がベタッとしている素材。
- 向いていない：写真のような複雑な背景（AI背景抜きの領分です）。iPhoneの写真形式（HEIC）は開けないことがあります。

## 仕組み

- 抜き方は2方式を切り替えられます。従来方式は、背景色との色距離をピクセルごとに計算し、画像の端から「背景色に近いピクセル」だけをたどって透明化します（連結した領域だけを抜くので、内側の同色が守られます）。
- 新方式「マスク先行」（試作）は、被写体らしい色（コア）を膨張→収縮で閉じて穴埋めし、「コア」と「閉じた輪郭の内側の穴」だけを保護します。外側の判定では、コアに加えて色の段差（輪郭の線）も壁にするので、薄い色の被写体でも内側の陰影が半透明に侵食されません。それ以外（外側や、輪郭の凹みのポケット）は色の近さで切り直すため、線の途切れから内側へ侵入しにくく、深い凹みの背景も四角く残りません。輪郭から離れた外側は、許容範囲内の色なら完全に抜くので、グラデーションの中間色も半透明に残りません。
- 背景色の自動判定はフチ全体の色を集計し、離れた色は最大4色まで拾います（2色背景やグラデーションの両端など）。
- 境界では、背景色との距離に応じて透明度をなだらかにし、背景色の混ざりを引いて色を戻すことで、ギザギザと色かぶりを抑えます。
- フチは、確定した輪郭のシルエットをフチ色で塗り、円周上にずらしながら重ね描きして太らせます。
- 処理はすべてブラウザ内で完結し、画像が外部に送信されることはありません。ネット接続も不要です。
