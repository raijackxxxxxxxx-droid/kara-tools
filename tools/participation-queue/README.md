# 参加枠まわし君（仮）

参加型配信の「次は誰？」をなくすための、配信者側の裏方ツールです。
参加回数が一番少ない人から順に「次の参加者」が決まるので、回数の偏りや「私まだですか？」が起きにくくなります。

ブラウザで開くだけで使えます。インストール不要、データの外部送信なし、無料です。

## 使い方

1. このページ（index.html）をブラウザで開く
2. 「参加者を追加」に名前を入れて追加（カンマ区切りで一括追加もできます。同名は追加できません）
3. 上部の「⭐ 次の参加者」に、次に遊ぶ人たちが表示されます（リスト側でもその人たちが光ります）
4. 1ゲーム終わったら「この枠で参加した（全員 +1）」を押すだけ。光が次の人たちへ移ります

### 枠数

設定の「参加枠」で、1回に遊ぶ人数を変更できます（初期値 3人）。

### 一時離脱（パス）と復帰

トイレ・お風呂などで一時的に抜ける人には、その人の **+** ボタンを押してください。
回数が増えて光が消え、次の人へ回ります。戻ってきたら **−** で元に戻せます。
並び順（到着順）は変わりません。

### 途中参加の初期値

途中から参加する人の「参加済み回数」をどう扱うか、設定で選べます。

| 設定 | 意味 |
|---|---|
| 0 | 初見さんが一番少ない人の回数に追いつくまで、毎回参加します（かなり優遇） |
| リストの最小値−1（初期設定） | 初見さん優先。次の枠に1回割り込めて、参加後は一番少ないグループに合流します |
| リストの最小値 | 一番少ないグループの最後尾に入ります（ゆるやかな優先） |
| リストの平均値 | 最初からいた平均的な人と同じ扱い（平等） |
| リストの最大値 | 一番多い人に合わせます（ずっと待っていた人が優先） |

最小値−1 は、最小値が 0 のときは 0 になります（マイナスにはなりません）。

### その他

- 「回数を全員0に」：回数だけリセットします
- 「全員削除」：リストを空にします
- 行の ✕ ：その人を削除します

## 仕様・注意

- データは保存されません。ページを閉じたり再読み込みすると、リストも回数もリセットされます
- 表示順は到着順で固定です。シャッフルはしません
- スマートフォンでも使えます（ボタンは大きめにしてあります）
- 動作保証はありません。配信本番の前に一度触って試すことをおすすめします
