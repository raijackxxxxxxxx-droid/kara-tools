# もじPNGメーカー（仮）

テキストを1行ごとに透過PNG画像にするツールです。
配信の演出素材（テロップ・定型文・合いの手など）づくりを想定しています。

ブラウザで開くだけで使えます。要ネット接続（Webフォントの読み込みのため）。

## 使い方

1. テキスト欄に文章を入れる（改行ごとに1枚の画像になります。空行はスキップ）
2. フォント・太さ・サイズ・文字色・縁取り・影を調整する
3. 「画像を作る」でプレビュー生成（設定を変えると自動で作り直します）
4. 保存は3通り：
   - 各画像の「保存」ボタン
   - PCならプレビュー画像を右クリック、スマホなら長押しで保存
   - 「一括保存（zip）」で全部まとめてダウンロード

## 設定項目

| 項目 | 内容 |
|---|---|
| フォント | Noto Sans JP / M PLUS Rounded 1c / しっぽり明朝 / 解星デコール / Yusei Magic（Google Fonts） |
| 太さ | 通常 / 太字 / 極太（フォントに無い太さは近いものになります） |
| サイズ | 文字の大きさ px |
| 余白 | 画像の周囲の透明部分 |
| 縁取り | 太さと色（角は丸く処理するので潰れにくい） |
| 影 | ON/OFF、色、ぼかし、距離（下方向） |

ファイル名は moji_01.png のような連番、zip は moji_png.zip です。

## 注意

- フォントは Google Fonts（オープンライセンス OFL）を使用しています。各フォントのライセンス範囲でご利用ください
- 画像はブラウザ内で生成され、テキストが外部に送信されることはありません（フォントの取得を除く）
- 動作保証はありません
